Aplicaciones Web

Las aplicaciones web son programas que podemos utilizar desde un navegador para estudiar, comunicarnos, comprar productos y realizar muchas otras actividades.

Objetivo del proyecto: conocer los conceptos básicos, las tecnologías, los tipos y las medidas de seguridad de las aplicaciones web.

Seguridad

Identificarás prácticas sencillas para cuidar tus cuentas y tus datos personales.
