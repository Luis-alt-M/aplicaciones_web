Conceptos básicos

Estos términos ayudan a entender cómo se crean y utilizan las aplicaciones web.

1. Aplicación web

Programa que se usa desde un navegador. Ejemplo: una aplicación de correo electrónico.

2. Página web

Documento que puede mostrar texto, imágenes y enlaces. Ejemplo: la página de contacto de una escuela.

3. Sitio web

Conjunto de páginas relacionadas. Ejemplo: el sitio oficial de una institución.

4. Navegador web

Programa que permite visitar páginas web. Ejemplos: Chrome, Firefox y Edge.

5. Servidor web

Equipo o programa que responde solicitudes y entrega páginas o datos.

6. Internet

Red mundial que conecta dispositivos y permite intercambiar información.

7. URL

Dirección de un recurso en la web. Ejemplo: https://www.ejemplo.com

8. Dominio

Nombre fácil de recordar que identifica un sitio. Ejemplo: ejemplo.com.

9. Hosting

Servicio que almacena los archivos de un sitio para que se pueda visitar por Internet.

10. HTTP y HTTPS

Protocolos que permiten transferir información web. HTTPS añade cifrado a la comunicación.

¿Cómo funciona una conexión web?

El usuario escribe una dirección en el navegador. El navegador envía una solicitud al servidor y recibe los recursos necesarios para mostrar la página.
